# Trin Assistant Command List

## Basic Commands
- "hello trin" or "hello trinity" - Wake up the assistant
- "goodbye" - Put the assistant to sleep
- "exit" or "quit" - Close the application

## System Information
- "what's the system status" - Get CPU, memory, disk, and network information
- "what time is it" - Get current time
- "what day is it" - Get current day
- "what's today's date" - Get current date
- "perform maintenance" or "clean up" - Run system maintenance tasks

## Weather Information
- "what's the weather" - Get weather for current location
- "what's the weather in [city]" - Get weather for specific city
- "what's the weather in [city], [country]" - Get weather for specific city and country

## News Updates
- "get news" - Get general news headlines
- "get technology news" - Get technology news
- "get business news" - Get business news
- "get sports news" - Get sports news

## Web Search
- "search for [query]" - Perform a web search

## File Management
- "organize files" - Organize files in Downloads folder
- "organize files in [directory]" - Organize files in specific directory

## Application Control
- "open [application]" - Launch an application
- "close [application]" - Close an application
- "kill [application]" - Force close an application

## Spotify Control
- "open spotify" or "launch spotify" - Open Spotify
- "spotify play" - Play music
- "spotify pause" - Pause music
- "spotify next" - Skip to next track
- "spotify previous" - Play previous track
- "spotify volume up" - Increase volume
- "spotify volume down" - Decrease volume
- "spotify mute" - Mute volume
- "spotify playlist [name]" - Play specific playlist

## System Control
- "shutdown" or "turn off" - Shutdown computer (60 second delay)
- "restart" - Restart computer (60 second delay)
- "cancel shutdown" - Cancel pending shutdown

## Notes
- The assistant is case-insensitive
- Some commands require specific applications to be installed (e.g., Spotify)
- Weather information requires an internet connection
- System maintenance runs weekly by default
- File organization creates folders for different file types:
  - Documents (PDF, DOC, TXT)
  - Images (JPG, PNG, GIF)
  - Videos (MP4, AVI, MOV)
  - Music (MP3, WAV, FLAC)
  - Archives (ZIP, RAR)
  - Programs (EXE, MSI)

## Troubleshooting
If a command doesn't work:
1. Make sure you're connected to the internet
2. Check if the required application is installed
3. Ensure you've said the wake word "hello trin" or "hello trinity"
4. Try speaking more clearly
5. Check the console for error messages
